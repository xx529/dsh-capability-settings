## 0. 术语与缩略

| 术语 | 含义 |
|---|---|
| 入口 | 首屏 hero 里的「✦ 能力决策」按钮（展开态面板 / 收起态能力条两处，同一动作） |
| 配置 Tab | 能力面板第三个域 Tab「Jev 模型」，全局面板中的配置表单 |
| 结果面板 | 点击入口后替换 hero 能力区内容的「✦ 能力决策」面板，**非**全屏 modal |
| 草稿 | 当前会话输入框里的纯文本（不含附件、队列、chip 占位符） |
| Noul | Jev 的一次 0–1 概率判断；本功能 = 一个能力一条 Noul，N 条合并为 **1 次请求** |
| 可切换能力 | 当前会话里能被技能/MCP 会话开关改写的条目（见 §6.2） |
| 手改 | 用户手动点勾选框产生的覆盖状态 |
| 冷会话 | 首屏尚无 live agent 的会话（会话未激活） |
| 能力决策 | 本功能的用户可见名称（旧称已废弃，见 §17 v1.2）：由 Jev 依据草稿为本会话能力打分并预勾选 |
| 能力决策区 | 配置 Tab 内的设置区（标题「能力决策」）：控制自动评分开关、停顿阈值、最少触发字数、最少修改间隔字符数 |
| 停顿阈值 | 输入停止多久后自动发起评分；默认 1000ms，范围 300–3000ms，步长 100ms |
| 最少触发字数 | 草稿字符数达到该值才允许自动触发；默认 10，范围 1–200 |
| 最少修改间隔字符数 | 自上次能力决策累计插入+删除字符数达到该值才允许再次自动触发；默认 4，范围 1–100 |
| 编辑基线 | 上一次能力决策（自动或手动）时的草稿快照，用于统计累计编辑量 |
| 自动触发 | 停顿计时到点自动发起评分（不需点击）；手动触发 = 点击「✦ 能力决策」 |
| 同草稿静默 | 自动触发被取消后，同一草稿不再自动触发，直到草稿内容变化 |

## 2. 设计原则（用于裁决后续细节）

| # | 原则 | 落到本规格 |
|---|---|---|
| P1 | 不新增浮层 | 结果面板复用 hero 能力区的位置与宽度，替换内容，无遮罩 |
| P2 | 一次请求 | 标题下固定「1 次请求」；不允许出现「每个能力一次请求」的观感 |
| P3 | 可逆 | 应用只启用勾选项、不关闭未勾选项、只写当前会话；重新评分可重来 |
| P4 | 手改最高 | 用户点过的行，阈值不再改变它；阈值只改「预勾选」 |
| P5 | 不隐藏 | 阈值不隐藏行；无匹配用提示行表达 |
| P6 | 可解释 | 每行同时给类型、名称、描述、分数数值、分数条，颜色不是唯一载体 |
| P7 | 键盘可完成全流程 | 入口 → 面板 → 调阈值 → 勾选 → 应用，全程无需鼠标 |
| P8 | 文案可直抄 | 所有用户可见字符串集中在本文件，实现直接引用 |
| P9 | 不打断输入 | 自动触发不弹 toast、不抢输入框焦点；状态只用能力条/面板内的弱提示表达 |

## 4. 入口规格（两态）

### 4.1 两态位置与外观

| 项 | 展开态（「本会话能力」面板） | 收起态（能力条） |
|---|---|---|
| 位置 | 标题行右侧按钮组，**位于搜索框左侧、收起按钮左侧** | 能力条右端，**紧邻并位于「配置」左侧** |
| 尺寸 | 112 × 26，圆角 8 | 112 × 26，圆角 8（与「配置」同高） |
| 图标 | `✦`（星芒，单色 `currentColor`，12px，与文字间距 4） | 同 |
| 文案 | `能力决策`（评分中：`评分中…`） | 同 |
| 样式 | 次要按钮：底 `rgba(97,175,239,.12)`、1px `rgba(97,175,239,.35)`、文字 `#8FBCFF`、12 Medium | 同（两处必须像素级一致，可被识别为同一动作） |
| hover | 底色 `.18`、边框 `.55` | 同 |
| 按下 | 底色 `.24` | 同 |
| disabled | 整体 opacity `.45`、`cursor: default`、hover 不变 | 同 |
| 引导态（未配置） | 边框与文字保持同款（**不禁用**），hover 加亮；追加 4px 蓝点提示 | 同 |
| 焦点 | 2px accent-soft 外环；`Enter`/`Space` 等价点击 | 同 |

- 两处入口共享同一状态机（§7），任一态变化另一处同步（同一次渲染内从同一份 store 读取）。
- 展开态与收起态切换（收起/展开）时按钮保持位置记忆，不产生闪烁。
- 文案在评分中变为 `评分中…`；应用进行中变为 `应用中…`（面板已替换内容时入口不可见，此文案用于多标签页/异常态）。

### 4.2 入口禁用条件（优先级从高到低，取第一条命中）

| 优先级 | 条件 | 入口表现 | 点击行为 | tooltip / aria |
|---|---|---|---|---|
| 1 | 应用进行中 | disabled，文案 `应用中…` | 无 | `正在应用所选能力` |
| 2 | 评分中 | disabled，文案 `评分中…` | 无 | `正在评分，请稍候` |
| 3 | Jev 配置读取中 | disabled，文案 `能力决策` | 无 | `正在读取 Jev 配置…` |
| 4 | 能力数据加载中 | disabled | 无 | `正在加载本会话能力…` |
| 5 | 草稿为空（`trim() === ""`） | disabled | 无 | `先在输入框写下你要做的事` |
| 6 | 可评分能力 `N = 0` | disabled | 无 | `当前会话没有可评分的技能或 MCP 服务器` |
| 7 | 可切换能力 `M = 0` | disabled | 无 | `当前会话没有可切换的能力` |
| — | **未配置 / 鉴权不完整** | **可用**，引导态 | 打开能力面板并选中「Jev 模型」Tab | `尚未配置 Jev 模型，点击去配置` |
| — | Jev 配置读取失败 | 可用（错误引导） | 打开结果面板错误态（`configError`），可重试 / 去配置 | `读取 Jev 配置失败，点击查看详情` |
| — | 就绪 | 可用 | 立即进入评分态并发起 **1 次**请求 | `根据输入框草稿，为技能和 MCP 打分并勾选相关能力（仅当前会话）` |

补充：

1. 优先级 1–7 任一命中时 `aria-disabled="true"` 且不派发点击事件（不用原生 `disabled` 属性，保证 tooltip 与焦点可达；键盘 Enter 被忽略）。
2. 未配置**不是禁用态**：用户首次点击必须能到达配置 Tab（否则死路）。但视觉上用「蓝点 + tooltip」暗示需要先配置。
3. 草稿**仅空白字符**（空格/换行）视为空。草稿含 chip 占位符（`\uE100-\uE11D`、`\uFFFC`）时先清洗再判空。
4. 入口不因「视觉不可见」（收起态/展开态切换）而丢失评分中状态：评分面板打开期间，原入口被替换区覆盖。
5. **自动触发的门槛高于按钮**：自动触发还要求草稿 ≥「最少触发字数」（默认 10）、自上次能力决策的编辑量 ≥「最少修改间隔字符数」（默认 4）、自动评分开关开启（默认关）（§4.4）；按钮只在草稿非空时可用。两者不互相替代。
6. 「等待停顿」不是禁用态：计时中入口仍可用，点击立即触发（等价手动）。
7. 自动评分关闭（默认）不影响入口可用性，只取消「自动触发」这一路径；此时入口 tooltip 提示可在配置中开启。
8. **草稿不可读**（槽 props 与 DOM 兜底都取不到草稿，见 §8.5 第 4 条）：入口禁用 + tooltip `无法读取输入框内容`；不提供点击报错路径，该条件下自动触发同样不启动。
9. 自动评分**默认关闭**（v1.4）：开启前入口 tooltip 为 `自动触发默认关闭 · 可在 Jev 模型 Tab 开启`（仍可点击手动触发）。

### 4.3 手动触发的点击分支

```
点击「✦ 能力决策」
├─ 配置读取失败 → 结果面板 configError 态（头部+说明+错误区+底栏；可 重试 / 去配置 / 取消）
├─ 未配置 / 鉴权不完整 → 打开能力面板，切到「Jev 模型」Tab；面板内顶部提示条（jev.unconfiguredTip）
├─ 草稿为空 → 不响应（禁用 + tooltip）
├─ 能力加载中 / N=0 / M=0 → 不响应（禁用 + tooltip）
└─ 就绪
   ├─ 记录「触发来源」（展开态 / 收起态）与「打开前形态」
   ├─ 入口立即 disabled（文案 `评分中…`）→ 防止双击
   ├─ 用**草稿快照**发起 1 次批量请求（N 条 Noul）
   └─ 结果面板替换 hero 能力区内容（同宽、同锚点，不遮输入框）
```


### 4.4 停顿自动触发（核心新增）

**只在 hero 相位生效**；会话进行中（首条消息后）不自动触发。**自动评分默认关闭**，需在「Jev 模型 → 能力决策」开启；关闭时手动按钮仍可立即触发。

```
草稿内容变化（trim 后不同）
└─ 条件检查（全部满足才计时）
   ├─ hero 相位
   ├─ 配置「输入停顿后自动评分」开关 = 开（默认关闭，需用户开启）
   ├─ Jev 已配置
   ├─ 草稿长度 ≥ 「最少触发字数」（默认 10）
   ├─ 距上一次能力决策的累计编辑量 ≥ 「最少修改间隔字符数」（默认 4）
   ├─ 无评分进行中 / 无应用进行中
   └─ 不在同草稿静默期（S3c）
   ├─ 满足 → 启动/重置停顿计时（长度 = 配置停顿阈值）
   │  ├─ 计时中状态行：「停顿 0.9s / 1.0s · 即将能力决策」（能力条或展开态标题行下方）
   │  ├─ 草稿再变化 → 重置计时
   │  └─ 计时到点 → 自动展开结果面板 + 进入评分中态（trigger=auto）
   │     ├─ 不弹 toast、不响铃、不移动输入框焦点
   │     ├─ 成功 → 结果（头部加「自动」徽标；无说明行）
   │     └─ 失败 → 对应错误态（同手动）
   └─ 不满足 → 不显示倒计时，回入口态；按钮仍可手动触发
```

| 规则 | 说明 |
|---|---|
| 计时重置 | 每一次草稿内容变化都重置；输入法组字期间暂停计时，`compositionend` 后重新起算 |
| 展示位置 | 收起态：能力条标题行下方一行弱提示；展开态：面板标题行下方一行；不新增浮层 |
| 倒计时精度 | 约每 100ms 刷新，显示 1 位小数（`0.9s / 1.0s`）；不给读屏做每步播报（`aria-live="off"`） |
| 到点动作 | 面板替换 hero 内容并进入评分中态；若结果面板已打开，则直接替换为评分中态（不重复展开） |
| 取消 | 自动触发后的「取消评分」→ 中止本次；面板回入口态；**同一草稿不再自动触发**（S3c），草稿变化后解除 |
| 关闭开关 | 立即取消计时与倒计时；能力条不显示任何自动触发提示；手动按钮保持可用 |
| 未配置 / 配置读取失败 | 静默跳过自动触发（不弹错误、不打断输入）；入口仍引导去配置 |
| 无 toast | 自动触发的开始/完成/取消都不弹 toast，只在面板内与能力条内表达 |
| 会话进行中 | hero 相位结束即停止计时；不补发 |

### 4.5 手动触发与自动触发的关系

| 维度 | 手动（点击「✦ 能力决策」） | 自动（停顿到点） |
|---|---|---|
| 门槛 | 草稿非空 | 草稿 ≥ 最少触发字数（默认 10）+ 自动评分开关开 + 已配置 + 自上次能力决策编辑量 ≥ 最少修改间隔（默认 4）+ 非静默 |
| 何时可用 | 任意时刻（含自动评分关闭、倒计时中、同草稿静默期） | 仅满足 §4.4 条件时 |
| 幂等 | 点击即触发；双击只 1 次 | 同草稿只 1 次；草稿变化才可能再次触发 |
| 焦点 | 打开面板时焦点移入面板标题 | **不移焦点**，输入框保持焦点（可继续输入） |
| 反馈 | 面板展开 + 状态行 | 面板展开 + 状态行 + 头部「自动」徽标（`title` 含停顿时长） |
| 取消后 | 关闭；同一草稿可再次手动触发 | 同草稿静默，直到草稿变化 |

- 倒计时期间点手动按钮：取消计时，立即触发一次（不重复请求）。
- 手动触发同样进入 S7，但 trigger=manual；结果与后续交互完全相同。

## 5. 「Jev 模型」配置 Tab

### 5.1 Tab 规则（三 Tab 增量）

### 5.3 字段规格

| 字段 | 控件 | 默认 | 校验/行为 | 已保存时展示 |

### 5.4 两种密钥模式

| 场景 | 交互语义 |
|---|---|
| A 直接填写 | 宿主保存密钥；浏览器此后只显示 `已保存 · 尾号 {last4}` 与 `更换`，**不回填明文** |
| B 环境变量 | 只保存变量名；评分/测试由宿主读进程环境；浏览器不保存、不展示值 |
| A→B 保存后 | 宿主侧清除已保存密钥；评分只读环境变量 |
| B→A 保存后 | 变量名保留但不生效；必须填写 API Key 才能保存成功 |
| 环境变量缺失 | 保存允许；`测试连接`/评分失败并给出 `宿主环境变量 {name} 未设置`；不静默回退 |
| 切换未保存 | 只改表单显示；离开发送即丢弃 |
| 密钥可见性 | DOM 与任何响应中不得出现已保存密钥明文；最多显示尾 4 位（仅 A 模式）与来源 |

| 项 | 规格 |
|---|---|
| 点击 | 用当前表单值发一次最小请求；不落盘、不改会话开关、不触发评分 |
| 进行中 | 按钮 `测试中…` 且禁用；结果区 `正在连接 Jev 服务…`；重复点击无效 |

| 未保存提示 | 表单与已保存值不一致时，结果行尾追加 `（测试的是当前表单值，保存后生效）` |
| 互斥 | 保存中禁用测试；测试中禁用保存 |

### 5.6 保存 / 恢复默认

1. 保存成功：写全局配置 → 轻提示 `Jev 配置已保存`（toast，2.5s）→ 密钥控件切 `已保存 · 尾号 {last4}` 并清空输入 → 保存按钮回次要样式。
2. 保存后**无需刷新页面/重启**；下次评分与测试使用新配置。已打开的结果面板不因保存而变化（需重新评分）。自动评分开关、停顿阈值、最少触发字数、最少修改间隔字符数同属全局配置，保存后立即生效；关闭开关时能力条立即停止倒计时。
3. 保存失败：保留输入；动作区下方错误条 `保存失败：{reason}` + `重试`，表单不清空。
4. 恢复默认：仅重置表单（Base URL 默认、模型默认、A 模式、变量名默认、API Key 清空）并给行内提示，**不弹确认框、不立即写配置**。
5. 配置作用域：全局；页面常驻 `全局配置 · 所有项目和会话共享`。

### 6.6 结果行

**行结构（从左到右）**

| 槽位 | 规格 |
|---|---|
| 勾选框 | 原生 `input[type=checkbox]` 16×16；勾选态 accent；`aria-label="选择 {能力名}"`；不可切换时 `aria-disabled="true"` 且不可勾选 |
| 类型徽标 | `技能`（accent-soft 底 / accent 字）或 `MCP`（绿 soft 底 / 绿字）；10px，圆角 4，padding 1×5，固定宽 34 对齐 |
| 名称 | 13px 正文，单行省略 + `title`；同分时按名称升序的依据是**原始名称**（区分大小写首次比较） |
| 描述 | 12px 次正文，**单行截断** + `title` 全量；空描述渲染 `—`（不占额外行高） |
| 分数条 | 72×4（可伸缩 56–88）；槽底 `rgba(255,255,255,.08)`，填充 accent；宽度 = 分数 × 100%；`aria-hidden`（数值已可读） |
| 分数数值 | 2 位小数（`0.82`），12px，tabular，右对齐；`aria-label="相关度 0.82"` |
| 不可切换原因 | 12px 弱色；置灰行在描述后追加 `· {reason}`，并 `aria-describedby` 指向该元素（见 §6.8） |
| （可选 P2）作用域标签 | `项目` / `全局` / `外部`，10.5px 弱色，名称后；宽度不足时隐藏，不进入必保清单 |

**行状态**

| 状态 | 视觉 | 交互 |
|---|---|---|
| 预勾选（分数 ≥ 阈值，未手改） | 勾选 + 正常亮度 | 可取消；取消即进入手改 |
| 低于阈值（未手改） | 未勾选 + 整行 `opacity: .55`（勾选框保持可点） | 可手动勾选；勾选后恢复正常亮度并进入手改 |
| 手改勾选（任意分数） | 勾选 + 正常亮度；左侧 2px accent 竖条标识「手动」 | 再点取消；阈值变化**不影响**该行 |
| 不可切换 | `opacity: .45`、勾选框禁用、原因后缀；分数仍显示 | 不可勾选；不进入「已选」计数；应用时跳过 |
| hover | 行底 `rgba(255,255,255,.03)`；手改行的左侧竖条保持 | — |

- 行高 56（单行）；窄容器两行时 72。行本身不可聚焦（避免双焦点），只有勾选框可聚焦。
- 描述与名称都来自能力列表的现有字段；**不允许**在 UI 层截断后参与排序。
- 排序由服务端分数决定，UI 不提供按名称/类型重排，也不提供「只看某类」。

| 槽位 | 规格 |
|---|---|
| 左 | 无（计数已在阈值行） |
| 右 | `重新评分`（次要）→ `取消`（次要）→ `应用所选（{n}）`（主按钮，最右） |
| 按钮高 | 30；间距 8；主按钮最小宽 120 |
| `应用所选` 禁用 | n = 0（无勾选）→ disabled + tooltip `至少勾选一项`；评分中/应用中 → disabled |
| 评分中 | 底栏只保留 `取消评分`（居中或右对齐，次要按钮）；`应用所选` 隐藏 |
| 错误态 | 底栏保留错误 CTA：`重试` / `去配置`（视分类）+ `取消`；不显示「重新评分/应用所选」 |

### 6.8 可评分 / 可切换集合与置灰口径

| 集合 | 口径 | 用途 |
|---|---|---|
| 可评分 N | 当前会话可枚举的技能 + MCP 条目（项目 + 全局；MCP 含外部注入） | 计数分母 `已选 n / N`；参与评分与排序 |
| 可切换 M | N 中能被「当前会话开关」改写的条目 | **仅用于入口可用性判定（M=0 → 入口禁用）与应用对象**；**不作为计数分母** |
| 不可切换 K = N − M | 两类：①冷会话尚无 live agent（`会话未激活`）；②外部注入实例按会话注入、`tools.restrict` 不可用（`不可在当前对话关闭`） | 行置灰 + 原因；应用跳过 |

- 不可切换行**不单独分组到底部**，与其它行一起按分数排序（用户能看到它其实很相关）。
- 不可切换行不可勾选，因此不会进入 n；`应用所选（n）` 的 n 是勾选数（只会由可切换项构成）。
- 不可切换是**动态**的：会话激活后重新评分，同一能力可能变为可切换；行内置灰原因随结果刷新（结果面板不再在头部汇总 K，v1.6）。
- 若 N > 0 但 M = 0：入口禁用（§4.2 优先级 7），不进入结果面板。

### 6.10 无匹配态（`noMatch`）

- 条件：所有可切换能力的分数都 `< 阈值`（最高分低于阈值）。
- 界面：**不隐藏列表**；在阈值行与列表之间插入提示行：
  `没有达到阈值 {t} 的能力，可调低阈值或手动勾选`（12px，橙 `#D19A66`）。
- `应用所选（0）` 禁用 + tooltip `至少勾选一项`；用户手改勾选后提示行保留、按钮随 n 更新。
- 提示行的出现/消失不改变列表滚动位置。

### 6.11 错误态

统一结构：头部（标题 + 模型徽标 + `×` 可用）→ 错误区（替换阈值行 + 列表）→ 底栏（`重试`/`去配置`/`取消`）；**无说明行/隐私行**（v1.6）。**不自动重试、不自动关闭**。

| 分类 | 标题 | 说明 | 主 CTA | 次 CTA |
|---|---|---|---|---|
| 401/403 `auth` | `评分失败：API Key 无效或无权限` | `请到「Jev 模型」Tab 检查 API Key 或环境变量。` | `去配置` | `取消` |
| 模型不可用 `model` | `评分失败：模型 {model} 不可用` | `请检查「Jev 模型」Tab 的模型名。` | `去配置` | `取消` |
| 网络 `network` | `评分失败：无法连接 Jev 服务` | `请检查网络后重试；若使用代理，请确认宿主可访问。` | `重试` | `取消` |
| Base URL 错 `baseUrl` | `评分失败：无法连接 Jev 服务` | `请检查 Base URL 与网络后重试。` | `重试` | `去配置` |
| 超时 `timeout` | `评分失败：请求超时` | `Jev 服务响应超时，请稍后重试。` | `重试` | `取消` |
| 超上下文 `context` | `评分失败：输入内容超出模型上下文上限` | `请缩短输入框草稿后重试。` | `重试` | `取消` |

| 配置读取失败 `configError` | `读取 Jev 配置失败` | `请稍后重试，或到「Jev 模型」Tab 检查。` | `重试` | `去配置` / `取消` |

- 错误文案**不得包含 API Key、环境变量值或草稿全文**；技术细节放 `title` 或次要行，不显示裸栈。
- 错误区高约 120，垂直居中；`role="alert"`。

## 8. 交互规则

### 8.1 排序（固定，用户不可改）

1. 主序：分数**降序**（按未取整原始分数比较；显示 2 位小数不参与比较）。
2. 同分（原始分数完全相等）：**技能在 MCP 之前**。
3. 仍同分：名称升序（不区分大小写的 Unicode 码点序）。
4. 仍相同：按首屏能力列表默认顺序（稳定排序兜底）。
5. 不可切换项**一起参与排序**，不单独分组。

### 8.2 阈值与勾选

| 项 | 规则 |
|---|---|
| 预勾选 | `分数 ≥ 阈值` 的可切换能力自动勾选（含等于）；`< 阈值` 未勾选、整行弱化 |
| 阈值变化 | 不隐藏行、不改变排序、**不重新请求**；只重算「未手改」行的预勾选 |
| 手改优先 | 用户手动切换某行后，该行进入「手动覆盖」；此后调整阈值**不再改变该行**。行左侧 2px accent 竖条标识 |
| 手改的允许范围 | 任意分数都可手改（含低于阈值行、含高于阈值取消）；不可切换行不可手改 |
| 重新评分 | 产生新结果：手改全部清空；按新分数与**当前阈值**重新预勾选；阈值数值保留 |
| 关闭后重开 | 视为新面板：阈值回 `0.50`、手改清空、结果重新请求 |
| 计数 | `已选 {n} / {N}`（单基数）：n = 当前勾选数（含手改；不可切换项不可勾选，故 n 只来自可切换项）；N = 参与评分的全部能力数（含不可切换） |
| 全选 | **不提供**「全选」按钮；阈值 0 等价全选可切换项 |
| 应用可用性 | n = 0 时 `应用所选` 禁用 + tooltip `至少勾选一项` |
| 无匹配 | 全部低于阈值时显示提示行，列表仍展示、可手改（§6.10） |

### 8.3 重新评分

| 项 | 规则 |
|---|---|
| 触发 | 底栏 `重新评分`；手动重评用于同一草稿或自动评分关闭时；自动评分开启时新草稿由 §8.4 停顿计时接管（同一草稿不会自动重发） |
| 输入 | **最新草稿**（点击瞬间读取，不用打开时的快照）；已保存的 Jev 配置 |
| 行为 | 进入 S7；当前结果被替换（不做新旧对比、不做差异高亮） |
| 阈值 | 保留当前滑杆值（面板未关闭） |
| 手改 | 全部清空 |
| 草稿为空 | 按钮禁用 + tooltip `输入框已清空`（S19e）；不发起请求 |
| 并发 | 评分中按钮禁用；同一时刻只允许 1 个评分运行 |

### 8.4 停顿计时、防抖、重复点击与竞态

**停顿计时与自动触发**

| 项 | 规则 |
|---|---|
| 计时起点 | 每次草稿内容变化（trim 后不同）重置计时；输入法组字（composition）期间暂停，`compositionend` 后重新起算 |
| 计时长度 | 配置「停顿阈值」（默认 1000ms，范围 300–3000ms，步长 100ms） |
| 最少触发字数 | 默认 10，范围 1–200；草稿 `trim()` 后字符数（Unicode 码点）≥ 该值才进入停顿计时 |
| 最少修改间隔字符数 | 默认 4，范围 1–100；以上一次能力决策（自动或手动）的草稿快照为基线，累计「插入字符数 + 删除字符数」≥ 该值才允许下一次自动触发 |
| 默认关闭 | 自动评分开关默认关：首次使用不自动触发、无倒计时；入口 tooltip `自动触发默认关闭 · 可在 Jev 模型 Tab 开启`；手动按钮可用 |
| 基线更新 | 每次能力决策（自动或手动）触发时把当前草稿快照设为新基线，累计编辑量清零 |
| 触发条件 | ① hero 相位；② 自动评分开关开（默认关）；③ Jev 已配置；④ 草稿长度 ≥ 最少触发字数（默认 10）；⑤ 自上次能力决策累计插入+删除字符数 ≥ 最少修改间隔字符数（默认 4）；⑥ 无评分/应用进行中；⑦ 不在同草稿静默期（S3c） |
| 编辑量统计 | 以上一次能力决策（自动或手动）的草稿快照为基线；累计「插入字符数 + 删除字符数」，替换按 1 次删除 + 1 次插入计；触发后基线更新、累计清零 |
| 阈值范围 | 最少触发字数 1–200（默认 10）；最少修改间隔字符数 1–100（默认 4）；保存后立即生效 |
| 默认关闭 | 自动评分开关默认关；首次使用不自动触发；入口 tooltip `自动触发默认关闭 · 可在 Jev 模型 Tab 开启` |
| 触发动作 | 计到点自动展开结果面板并进入 S7（trigger=auto）；不点按钮、不弹 toast、不移动输入框焦点 |
| 倒计时 | 能力条/展开态标题行显示 `停顿 0.9s / 1.0s · 即将能力决策`（约 100ms 刷新，1 位小数）；不进 `aria-live` |
| 草稿变化 | 计时重置；已展开的结果面板不立即重发，由新草稿在停顿到点后按 auto 重新评分（S7） |
| 取消/静默 | 自动触发后的 `取消评分` → 中止并进入 S3c：同草稿不再自动触发；草稿变化后解除 |
| 手动优先 | 倒计时期间点按钮立即触发（取消计时，只发 1 次）；手动触发只要求草稿非空 |
| 关闭开关 | 立即取消计时与倒计时；手动按钮保持可用；不弹提示 |
| 会话进行中 | 不自动触发（hero 相位结束即停） |

**防抖、重复点击与竞态**

| 场景 | 规则 |
|---|---|
| 入口点击 | **不防抖**，点击即进入 S7 并立即禁用入口 → 双击/连点只产生 1 次请求（验收：请求计数 = 1） |
| 草稿变化 | 只影响状态判定：结果态下 300–500ms 防抖后更新「草稿已更新」提示（S19/S19e），**不自动请求** |
| 阈值拖动 | 本地即时重算勾选，不做请求、不做防抖（无网络） |
| 应用点击 | 点击后按钮立即 `应用中…` 并 disabled；双击只执行一次写入 |
| 评分运行标识 | 每次评分生成单调递增 run id；响应仅当 run id 为最新且面板仍打开时生效，否则丢弃 |
| 关闭后晚到 | 关闭/取消后返回的结果直接丢弃，不弹窗、不写状态 |
| 重试 | 用户显式点击；不自动重试、不指数退避 |
| 多标签页 | 按「最后一次操作生效」，不提示冲突（本期） |

### 8.5 草稿读取与变化

1. 首选宿主槽 standardProps：`useInput(s => s.draft)`（订阅式；hero 与 composer 相位均可用，已由调研 §B4 确认 API 存在）。
2. 次选 `props.input.draft`（点击时取当前值）。
3. 降级：`[data-composer-card] [data-composer-input]` 的 `innerText`（contenteditable，**没有 value**），清洗 `\uE100-\uE11D`、`\uFFFC` 占位符与零宽字符。
4. **全降级（旧外壳 / 宿主 DOM 结构变化）**：优先用第 3 条的 DOM 兜底读取；若槽 props（`useInput` / `input.draft`）与 DOM 兜底**都读不到草稿 → 入口禁用** + tooltip `无法读取输入框内容`，不提供「点击后报错」路径（禁用条件见 §4.2 补充第 8 条）。
5. `trim()` 后为空 → S3。
6. 草稿快照 = 触发评分那一刻的纯文本；**附件、队列、chip 仅作为占位符不进入请求**；提示用户「基于输入框草稿」即指该纯文本。
7. 自动触发额外要求 `trim().length ≥ 最少触发字数`（默认 10，范围 1–200；按 Unicode 码点计，含中文）；不足时只允许手动触发。
8. 编辑量门限：以上一次能力决策（自动或手动）的草稿快照为基线，累计「插入字符数 + 删除字符数」≥ 最少修改间隔字符数（默认 4，范围 1–100）才允许下一次自动触发；触发后基线更新。手动触发不受字数/编辑量限制（只要求非空），但同样更新基线。
9. 输入法组字（IME composition）期间不启动计时、组字结束（`compositionend`）后按新草稿重新起算，避免把中文半成品发送出去。

### 8.6 应用

| 项 | 规则 |
|---|---|
| 写什么 | 仅对**勾选**的可切换能力：确保当前会话启用；**未勾选的能力保持现状**（不关闭、不改项目默认） |
| 作用域 | 仅当前会话、内存态；与现有会话开关语义一致 |
| 跳过 | 不可切换项跳过；成功提示带跳过数 |
| 已是目标态 | 不重复写；全部已启用时提示 `所选能力已在当前会话启用` |
| 常规会话 | 成功 → 关闭面板 → 还原收起态能力条 → chips 回显 + 计数更新 → toast `已应用 {n} 项能力（仅当前会话）` |
| 冷会话 | 成功 → 立即回显 chips + toast `已加入本会话，发送首条消息后生效`；开关排队，首条消息发出后真正生效（依赖宿主能力，见 §16 O-1） |
| 失败 | 停留面板、保留勾选与滚动；错误条 `应用失败：{reason}` + `重试`；**尽力回滚**本次已提交修改；回滚失败追加 `部分修改可能未回滚，请刷新页面或到能力面板确认` |
| 焦点 | 成功后焦点回到触发入口（展开态或收起态对应按钮）；失败后焦点留在错误条 `重试`（若错误条可聚焦）或主按钮 |
| 刷新页面 | 会话开关按现有语义回项目默认（不持久化） |

## 9. 键盘与可访问性

### 9.1 语义与焦点

| 项 | 规格 |
|---|---|
| 结果面板 | `role="dialog"`、`aria-modal="false"`（非模态，不阻断输入框）、`aria-labelledby` 指向标题 id、`aria-describedby` 指向头部状态节点（结果态无说明行，v1.6） |
| 打开（手动触发） | 焦点移到标题容器（`tabindex="-1"`，不显示焦点环）；读屏播报 `✦ 能力决策` + 当前状态（评分中/结果） |
| 打开（自动触发） | **不移动焦点**：输入框保持焦点，用户可继续输入；只通过 `aria-live="polite"` 播报「停顿时长已达，已自动发起评分」；不抢滚动位置 |
| 关闭 | 焦点回到**触发入口**（记录来源：展开态面板按钮 / 收起态能力条按钮） |
| 面板内 Tab 顺序 | `×` → 阈值滑杆 → 结果行勾选框 × n（逐行）→ `重新评分` → `取消` → `应用所选`；评分中：`取消评分`；错误态：错误 CTA → `取消` |
| 阈值行 | 滑杆是原生 range，`aria-label="相关度阈值"`、`aria-valuetext="{0.50}"`；`←/→` 0.05、`Home/End` 0/1、`PageUp/PageDown` 0.1 |
| 结果行 | 只有勾选框可聚焦；`aria-label="选择 {能力名}"`；不可切换时 `aria-disabled="true"` + `aria-describedby` 指向原因文本 |
| Esc | 结果态 / 错误态 / S19 → 关闭（= 取消）；评分中不响应；应用中不响应；输入框内 Esc 沿用宿主行为 |
| 焦点环 | 全部可聚焦元素 `:focus-visible` 2px accent-soft 外环 + 1px 描边；鼠标点击不出现竖条 |
| 动效 | `prefers-reduced-motion: reduce` 时骨架不呼吸、toast 直接淡入无位移 |

### 9.2 状态播报（`aria-live="polite"`）

- 常驻一个视觉隐藏（`sr-only`）的状态节点，放在头部标题之后（结果面板无说明行，v1.6）；内容随状态变化：
  - 评分中：`正在评分… · 1 次请求 · {N} 个能力`
  - 完成：`评分完成，共 {N} 个能力，已勾选 {n} 项`
  - 无匹配：`没有达到阈值 {t} 的能力，可调低阈值或手动勾选`
  - 错误：错误标题 + 说明（`role="alert"` 区域）
- 阈值变化不播报整段（避免朗读噪音），只通过滑杆自身的 `aria-valuetext` 反馈；勾选框切换由原生读屏播报。
- **停顿倒计时不进 aria-live**（`aria-live="off"` 或 `aria-hidden="true"`），避免每 100ms 打断读屏；只在自动触发开始（`停顿时长已达，已自动发起评分`）与评分完成（`评分完成，共 {N} 个能力，已勾选 {n} 项`）各播报一次。
- 应用成功 toast 用 `aria-live="polite"`；应用失败错误条 `role="alert"`。

### 9.3 键盘速查

| 按键 | 作用域 | 行为 |
|---|---|---|
| `Tab` / `Shift+Tab` | 面板 | 按 §9.1 顺序移动 |
| `←` / `→` | 阈值滑杆 | ±0.05 |
| `Home` / `End` | 阈值滑杆 | 0 / 1 |
| `PageUp` / `PageDown` | 阈值滑杆 | ±0.1 |
| `Space` | 结果行勾选框 | 勾选/取消（手改） |
| `Enter` | 主按钮 | 触发对应动作 |
| `Esc` | 面板 | 关闭（评分中/应用中除外） |

### 9.4 对比度与颜色

- 正文/次级文字对比度 ≥ 4.5:1；分数条与勾选态不能是唯一信息载体（同时有数值、勾选符、文本原因）。
- 低于阈值弱化用整体透明度 `.55` 时，名称与数值仍需 ≥ 3:1（若实测不足，改为只弱化分数条与描述，名称保持）。
- 错误红、成功绿的同时必须有文字（不靠颜色单独表达）。

## 10. 窄容器降级

hero 宽度 = 输入卡宽度（通常 680–920，最窄约 520）。断点以**面板可用宽度**（`@container`）判断，不用视口宽度。

| 宽度 | 规则 |
|---|---|
| ≥ 720 | 正常单行：阈值行单行；结果行单行；底栏单行右对齐 |
| 560–719 | 阈值行拆两行：滑杆一行、`0.50` + `已选 n / N` 一行；结果行两行：第一行 `勾选框 + 徽标 + 名称 + 分数数值`，第二行 `描述 + 分数条（全宽）`；行高 72；底栏三按钮允许换行（右对齐或均分），触控高 ≥ 44 |
| < 560 | 在上一档基础上：描述隐藏（仅 `title`）；类型徽标保留；名称省略更激进（≥ 6 字符 + 省略号）；`重新评分` 与 `取消` 合并为一行均分，`应用所选` 独占一行（主按钮全宽） |
| 任意窄 | **不得出现横向滚动**；分数数值、勾选状态、不可切换原因、应用按钮必须始终可见或可滚动到达 |
| 高度受限 | `max-height = 视口底 − 面板顶 − 24px`；只有列表滚动；头部/说明/阈值/底栏固定；骨架不撑破面板 |

- 倒计时在窄容器缩短为 `0.9s / 1.0s`（`auto.entry.waiting.short`），不换行；「自动」徽标在 < 560 隐藏（其 `title` 仍含停顿时长，语义不丢）。
- 展开态入口按钮在标题行极窄时仍保留（`管理全部 ↗` 可先收进溢出菜单；「✦ 能力决策」不进溢出）。

## 14. 边界与明确不做

1. 不做全屏 modal / 抽屉 / 新浮层；结果面板只替换 hero 内容。
2. 不做自动重试、自动轮询、自动重新评分。
3. 不做「全选/全不选」按钮。
4. 不做结果筛选、按名称/类型重排、分组折叠。
5. 不做「未勾选即关闭」——应用只启用勾选项。
6. 不改项目默认、不写持久化配置（除 Jev 配置本身）。
7. 不在会话内顶部「能力」Tab 放能力决策入口（无输入框、无草稿）。
8. 不在输入框工具栏新增按钮。
9. 不展示 API Key 明文；不把密钥写入浏览器存储。
10. 不在 UI 层截断描述后参与评分（评分用完整字段）。
11. 不在会话进行中（首条消息后）自动触发；不做后台/轮询式自动评分。
12. 自动触发不弹 toast、不响铃、不抢输入框焦点。
13. 不用同一草稿重复自动触发（取消后也不）。
