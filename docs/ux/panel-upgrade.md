## 1. 背景与目标

### 1.1 三条用户需求

1. **快捷消息整个功能模块去除**：域 Tab 只剩「技能 / MCP」。
2. **技能明细看得到完整内容**：详情里展示 `SKILL.md` 正文，以及该技能目录下的其他文件，可在面板内逐个查看。
3. **选中域 Tab 后同时清楚看到「全局有什么、项目有什么」**，减少点击。

### 1.3 目标：点击预算（可验收）

| 任务 | 现状 | 新方案 |
|---|---|---|
| 知道「全局有什么、项目有什么」 | 至少 1 次 Tab 切换，且永远只看到单侧 | **0 次点击**（首屏两组组头 + 计数 + 首行可见） |
| 比较同名技能"谁生效" | ≥2 次切换 + 记忆比对 | **0 次点击**（同屏 + 关系标签 + tooltip 互指） |
| 启用/禁用一个技能或项目内屏蔽全局技能 | 切 Tab → 行 → 详情 → 按钮（≥3 步） | **1 次点击**（行尾开关，v2 起统一） |

| 查看 MCP 某工具的参数 | 探测后翻找/无入口 | **2 次点击**（详情展开「工具与参数」→ 点工具） |
| 切到 MCP 域 | 1 次 | 1 次（不变） |

### 1.4 非目标

- 不重做外壳（侧栏、会话头部、输入框）与「会话内能力 Tab」；本规格只覆盖侧栏「能力面板」主区域页。
- 不新增创建/编辑技能的富文本编辑器（沿用现有安装/编辑对话框）。
- 不改 MCP 挂载、`restrict`、探测的宿主语义；只改呈现。
- 不做市场/说明页风格的内容，页面保持工具属性。

## 2. 设计原则与约束

1. **同屏优于切换**：作用域信息用「分组 + 计数 + 组内滚动」表达，不用 Tab 二选一。
2. **状态就地可见**：来源、格式、启用、覆盖关系、挂载状态都必须在行上可读，详情只做展开。
3. **信息前置**：正文（SKILL.md）是技能的主体，必须成为详情页主体，不再是附属字段。
4. **零新依赖**：文件类型用 11px 文本后缀标签（`MD` / `PNG` / `JSON`…），不用新图标库；Markdown 用自研轻量渲染或原文等宽展示；骨架用纯 CSS。
5. **键盘可达、可读屏**：所有行内控件（开关）用 Tab 可达；列表用 `listbox/option` 语义；状态点必须带 `sr-only` 文本。
6. **只读即置灰，不是隐藏**：只读来源（`.claude` 兼容根、外部注入 MCP）的不可用动作置灰 + tooltip 说明原因，让用户理解「为什么不能改」。
7. **每行只给一个开关**（v2）：行内唯一控件是行尾开关；其余动作全在详情，不做 hover-only 功能、不做二级菜单。

## 3. 信息架构

### 3.1 层级

```
侧栏「能力面板」(sidebar.panellist)
└─ 主区域整页 · 能力面板
   ├─ 页面头部
   │  ├─ 标题行：能力面板 + 当前工作区路径 + 项目作用域下拉
   │  └─ 域 Tab：[ 技能 · 计数 ] [ MCP · 计数 ]        ← 只有两个
   ├─ 工具条：跨两组搜索框 + 主 CTA（安装/添加）
   └─ 内容区（左列表 320 / 右详情 864）
      ├─ 技能域
      │  ├─ 组 A「本项目 · N」  ← 独立滚动
      │  └─ 组 B「全局 · N」    ← 独立滚动
      └─ MCP 域
         ├─ 组 A「本项目 · N」
         ├─ 组 B「全局 · N」
         └─ 组 C「外部注入 · N」（只读）
```

### 3.2 域 Tab（只剩两个）

- 标签文案：`技能` / `MCP`，字号 13px/500，Tab 高 34，容器高 40，**通栏两等分**（与现状视觉一致，删掉一个即可，不新增样式）。
- **计数与标签同一行**（v2 原型）：`技能 12`、`MCP 9`。数字 11.5/500、`--skp-text-3`，与标签间距 6；选中态数字与标签同色（`--skp-text`）。计数字号小一档、不做独立胶囊（原型帧 01/03 即此形态）。计数口径：
  - 技能 = 项目条目数 + 全局条目数（含只读、含屏蔽占位，不去重）；
  - MCP = 项目配置条目数 + 全局配置条目数，**不含**外部注入（外部在组 C 单独计数）。
  - 计数必须来自与列表同一份响应，禁止为此额外发请求；加载中显示 `—`；搜索**不改变** Tab 计数（Tab 计数是总量）。
- 默认域：`技能`。保持现有默认（`panel.tsx:69`）。
- 快捷键（可选，P2）：`⌘/Ctrl+1` 技能、`⌘/Ctrl+2` MCP。**不写进原型首屏**，实现有空再加。

### 3.3 作用域呈现：同屏分组（主方案）

**结论：取消「项目 / 全局」二选一 Tab，改为同一列表内两个带组头的分组，各自独立滚动；搜索同时作用于两组。**

具体规则：

1. **顺序**：本项目在前，全局在后。外部注入（MCP）排最后。
2. **组头（sticky，高 36）**：
   - 左：组名 `本项目` / `全局` / `外部注入`（13px/600）+ 计数胶囊 `3`（11px，`--skp-fill` 背景，圆角 999）。
   - 右：一句话说明（11px，`--skp-text-3`）：
     - 本项目：「随项目走 · 只在本项目生效」
     - 全局：「所有项目共享 · 改动影响全部项目」
     - 外部注入：「运行时注入 · 只读」
   - 组头不做折叠开关（避免再增一个隐藏信息的状态）；仅在**空组**时折叠为 48 高引导行。
3. **独立滚动**：两组各自 `overflow-y: auto`，高度 `flex: 1 1 0`、`min-height: 168`。这样无论项目侧有多少条，全局组的组头和至少 2 行**始终同屏可见**，这是"减少点击"的核心机制。
   - 某一组为空 → 该组高度降为 48 的空态行，剩余空间让给另一组。
   - 两组都为空 → 列表中轴显示整块空态（见 §5.10 / §6.6）。
   - **例外**：MCP 的「外部注入」组为空时**整组不显示**（不占空态行），见 §6.1。
   - 列表整体高度不足（主区高度 < 640）时退化为「单滚动 + 粘性组头」。
4. **搜索跨两组**：一个搜索框，输入即同时过滤两组；组头计数变为 `匹配/总数`（如 `本项目 · 2/5`）；某组无匹配时该组显示 36 高「无匹配」行，而不是整组消失（保持结构稳定，用户不会以为数据丢了）。
5. **选中只属于一行**：跨组唯一；切域时保留（见 7.5）。

**为什么能减少点击（机制说明）**

- 现状把"另一侧有什么"编码在 Tab 状态里，要知道必须切换（1 次点击 + 1 次滚动 + 记忆）；
- 新方案把两侧信息**同时呈现为同一屏的两段**：组头计数回答了"有多少"，首行回答了"有什么"，关系标签回答了两者关系；
- 主 CTA 与搜索放在顶部且跨两组，用户不需要先选作用域再操作（现状必须先选项目/全局才能点对按钮）。

**备选方案与取舍**

| 方案 | 描述 | 优点 | 缺点 | 结论 |
|---|---|---|---|---|
| **A. 同屏分组 + 双段独立滚动（采纳）** | 一个列表列，两段各自滚动 | 两侧恒可见；保留现有行/详情布局，改动可控 | 双滚动条；每段可见行数变少 | ✅ 主方案 |
| B. 同屏分组 + 单滚动 | 一组接一组，粘性组头 | 实现最简单、滚动条唯一 | 项目条目多时要滚过整组才看到全局 | 备选（小数据量/低高度时降级为此） |
| C. 矩阵对比表 | 行=能力，列=[本项目][全局]，格子里放状态 | 覆盖关系最直观；密度最高 | 320px 列表放不下描述与行内开关；详情无位置；移动/窄屏不可用 | ❌ 仅适合"差异审计"页，不适合作日常管理 |
| D. 左右双列 | 左列项目、右列全局，中间详情 | 两侧同时可见 | 1184 主区扣掉详情后每列 <200，行放不下名称+状态；窄屏直接崩 | ❌ |
| E. 保留 Tab + 两侧计数 | 仍二选一，但 Tab 上显示计数 | 改动最小 | 仍需点击；跨组操作与比较依旧要来回切 | ❌ 不满足需求 3 |
| F. 筛选 chips（全部/只看本项目/只看全局） | 作为 A 的**增强**（P2），不是替代 | 长列表时快速聚焦 | 若做成主入口就会退化成 Tab | 🟡 可选增强，默认「全部」；实现时放在工具条右侧的筛选图标内，不做成 Tab |

> **已定稿（Lead 2026-10-23）**：采用 A（同屏两大组 + 独立滚动 + 组头计数，空组折叠 48）。B 仅作为实现内部的低高度降级（主区高度 < 640 时由实现自行切换），不作为产品方案。

### 3.5 同名 / 同键覆盖关系（技能与 MCP 共用语义）

宿主按 rank 让**项目条目遮蔽全局同名条目**。面板必须把这条关系讲清楚，而不是让用户在两个 Tab 里猜。

| 情况 | 项目侧那一行 | 全局侧那一行 |
|---|---|---|
| 仅全局存在 | 不出现 | 正常行，行尾开关可「在本项目禁用/恢复」；安装/导出等在详情 |
| 仅项目存在 | 正常行（可启停） | 不出现 |
| 项目副本 + 全局同名 | 标签 `覆盖全局`（tooltip：同名全局技能在本项目被本条目遮蔽；项目副本生效） | 标签 `项目副本生效中`（灰化，tooltip：本项目生效的是项目副本），点击可跳到项目行 |
| 本项目已禁用全局（shadow stub） | 该行 = 屏蔽占位，标签 `屏蔽占位`，状态点空心灰；行尾开关拨到开 =「恢复」 | 标签 `本项目已禁用`，行尾开关拨到开 =「在本项目恢复」 |
| MCP：项目引用/导入 + 全局同名 | 标签 `引用` / `导入` | 标签 `被本项目遮蔽` |
| MCP：项目同名覆盖 | 正常行（可启停/编辑） | 标签 `被遮蔽`（灰化，不可启停） |

**互跳交互**：`项目副本生效中` / `覆盖全局` / `被遮蔽` 标签可点击（或行尾 `↗`），一次点击滚动另一组的对应行并选中；滚动用 `scrollIntoView({block:'nearest'})`，不改变搜索词。

## 4. 布局与尺寸（1440×900）

### 4.1 画框分区

画框 1440×900 = **外壳侧栏 256×900（只作语境，不是本页内容）+ 主区 1184×900**。

```
主区 (x=256, w=1184, h=900)
├─ 页面头部                y 0    h 88   （下边框 1px）
│  ├─ 标题行               y 0    h 48   padding 0 20
│  └─ 域 Tab 行            y 48   h 40   padding 0 20
├─ 工具条                  y 88   h 52   padding 0 18 （下边框 1px）
└─ 内容区                  y 140  h 760  display:flex
   ├─ 列表列  w 320（含右侧 1px 分隔，padding 8 8 12）
   │  ├─ 本项目组  flex 1 1 0 min-h 168（组头 36 + 独立滚动）
   │  ├─ 8px 间隙 + 1px 分隔
   │  └─ 全局组    flex 1 1 0 min-h 168
   └─ 详情列  w 864（padding 20 24 → 内容宽 816）
```

| 区域 | 关键尺寸 |
|---|---|
| 标题行 | h 48；`h2` 17/24 600（沿用现状 `.skp-title-main h2`）；工作区路径 12.5 单行省略（最大 60ch）；右侧项目下拉 200×34（沿用 `.skp-dd-btn`） |
| 域 Tab | 容器 h 40（padding 3），Tab h 34，圆角 8，间隙 2，字号 13/500 |
| 工具条 | h 52；搜索 36 高、圆角 8、左内边距 36（放大镜 15px）；主 CTA 32 高 pill；与搜索间距 12 |
| 列表列 | w 320；左右 padding 8；组头 36；行间距 2 |
| 分组 | 每组 `flex:1 1 0`、`min-height:168`；空组折叠为 48 |
| 技能行 | h 76（padding 8/9 + 名称 20 + 标签 18 + 描述 18 单行 + 间距 3） |

### 5.4 行尾统一开关（v2 定稿：无文字按钮、无 `⋯` 菜单）

**已确认原型 v2 的核心理念：行 = 扫读 + 一个开关；动作 = 全部在详情。** 每行右端统一为「短 label + 30×18 开关」，不再有行内文字动作按钮或二级菜单。

| 行类型 | label | 开（knob 右） | 关（knob 左） | 点击行为 | 置灰 / tooltip |
|---|---|---|---|---|---|
| 项目 · 普通可写 | `启用` | 模型与用户均可用（整体启用） | 已禁用（用户与模型都不可调用） | `setEnabled(next)`；`partial`（仅一个方向可用）显示为开，tooltip 标注「部分禁用」 | 只读来源 → 置灰 |
| 项目 · 屏蔽占位 | `启用` | —（恢复态） | 已禁用（本项目屏蔽同名全局） | 关 → 开 = `enableInProject`（删除占位） | 无工作区 → 置灰 |
| 全局 · 未被遮蔽 | `启用` | 本项目可用 | 已在本项目禁用 | 关 = `disableInProject`（生成占位）；开 = `enableInProject` | 无工作区 → 置灰 |
| 全局 · 本项目已禁用 | `启用` | 本项目可用 | 已禁用（占位存在） | 开 = `enableInProject` | 无工作区 → 置灰 |
| 全局 · 项目副本生效中（`projectShadow === "skill"`） | `启用` | 置灰、knob 在右 | — | 不可点 | tooltip「本项目生效的是项目副本，请在项目副本上操作」 |
| 只读来源（`.claude`） | `启用` | 置灰、按读到的状态摆位 | 置灰 | 不可点 | tooltip「只读来源，无法修改或删除」 |

- **尺寸/颜色**：30×18、knob 14、圆角 999；开 = `--skp-accent`；关 = 白 13%；置灰 = 轨道白 8% + **knob 在右**；label 10.5 / `--skp-text-3` / 宽 32 / 右对齐，与开关间距 6；label 在置灰时**不降透明度**（与普通行一致）。
- **置灰 ≠ 关闭**：置灰态与关态都可能是浅色轨道，唯一区别是 knob 位置（置灰恒在右）与可交互性；因此置灰必须同时具备 tooltip 与 `aria-disabled`，不能让用户只靠颜色判断。项目副本生效中的行**状态点仍为绿**（该全局技能可用），开关置灰表达"本项目不能直接操作"。
- **状态映射**：`checked = invocationState !== "none"`；`partial`（仅用户或仅模型）→ 视觉为开，但 tooltip 写「仅用户可用 / 仅模型可用」；细粒度两方向开关保留在详情（P2，原型未画）。
- **执行**：点击**不改变选中**（`stopPropagation`）；乐观切换 → 静默重拉确认；失败回滚 + 详情错误条；执行中开关 `disabled`（不换 loading 图标）。
- **键盘**：开关是原生 `input[type=checkbox][role=switch]`，`Space` 切换；行 `Enter` 只打开详情；`Tab` 从行进入开关。
- **触控**：开关外层 32×32 可点区；行高 76 本身远超 44。
- **无障碍**：`aria-label="启用 <技能名>"`；置灰时 `aria-disabled` + tooltip 文本进 `aria-describedby`。
- **MCP 行尾**同为「label + 开关」，label 固定 `默认`，语义不变（新建对话默认启用），见 §6.3。

### 5.9 Markdown 预览渲染（零新依赖，v2 版式）

### 6.1 分组（三组，外部注入单列）

**结论：外部注入单独成组（组 C），不混入全局组。**

理由：外部注入的生命周期、可写性、开关能力都与配置条目不同（只读、无编辑/删除、`restrictable` 时只能按项目默认关闭，`mcp-panel.tsx:531-596`）。混排会让用户反复问"为什么这个不能编辑"。单列后组头文案直接回答这个问题。

**已定稿（Lead 2026-10-23）**：外部注入单列第三组，且**仅在该组非空时出现**；为 0 时不占位、不显示空组。

备选：并入全局组并加 `外部` 标签，组内排序置底。优点：列表更短、与"运行时实例也在全局可见"的心智一致；缺点：不可写条目与可写条目混在一个滚动区。**若 Lead 认为三组太碎，可退到该备选**。

## 7. 交互细节

### 7.1 默认选中

1. 进入面板 → 域默认「技能」；数据到达后：
   - 若本项目组非空 → 选中第一行（滚动到顶部）；
   - 否则若全局组非空 → 选中第一行；
   - 否则不选中，列表显示空态，详情显示空态。
2. 切域返回 → 恢复该域上次选中的 `rowKey`（跨组唯一键 `${group}:${source}:${name}`）；若该行已不存在 → 选同组邻近行（优先下一行，否则上一行），再不行按 1 的规则。
3. 搜索导致选中行被过滤掉 → 保留选中（详情仍可看），但列表里不显示；清空搜索后恢复高亮。若用户此时按 ↑↓ 则以当前过滤结果重新定位。

### 7.2 搜索

- 位置：工具条左侧，跨两组；占位符 `搜索技能…` / `搜索 MCP 服务器…`（技能域与 MCP 域不同）。
- 行为：即时本地过滤（无网络请求），匹配字段：技能 = `name` + `description`；MCP = `key` + `summary` + `transport` + 命令/URL（不区分大小写，去首尾空格）。
- 高亮：命中片段用 `<mark>` 样式（accent-soft 底 + 文字不变），列表与详情标题都高亮；高亮不得影响省略号截断。
- 计数：组头显示 `匹配/总数`；两组都 0 时列表整块显示「没有匹配…」空态。
- 清空：搜索框右侧出现 `×`（24×24），点击清空并保留选中；`Esc` 同效。
- 不改变：Tab 计数、组的顺序、组的空态行。
- 搜索不跨域（技能域只搜技能）。

### 7.3 键盘

| 按键 | 作用域 | 行为 |
|---|---|---|
| `↑` / `↓` | 列表 | 上/下移动选中；到组边界自动跨组；不循环 |
| `Home` / `End` | 列表 | 组内首/尾（跨组时作用于当前组） |
| `PageUp` / `PageDown` | 列表 | 翻页（约 5 行） |
| `Enter` | 列表 | 打开详情：选中项已显示详情时，把焦点移到详情第一个可操作按钮 |
| `Space` | 行尾开关 | 切换开关（能力域=启用/在本项目禁用；MCP=默认），不打开详情 |
| `/` | 页面 | 聚焦搜索框（输入框/文本域内不生效） |
| `Esc` | 搜索框 | 有内容 → 清空；无内容 → 焦点回列表 |
| `Esc` | 详情 | 焦点回列表当前行 |
| `Esc` | 对话框 | 关闭（等同取消） |
| `←` / `→` | 目录树 | 收起 / 展开文件夹 |
| `Enter` | 目录树 | 打开文件并把焦点交给阅读器正文 |
| `Tab` / `Shift+Tab` | 全局 | 域 Tab → 搜索 → 主 CTA → 列表 → 选中行的行尾开关 → 详情动作区 → 目录树 → 阅读器；MCP 详情中「工具与参数」→ 工具列表 → 参数表（只读，靠 ↑↓ 浏览） |

- 快捷键不劫持浏览器：`/` 只在 `document.activeElement` 不是 input/textarea/contenteditable 时生效；`⌘/Ctrl+F` **不**拦截（交给浏览器/外壳）。
- 焦点可见：所有可聚焦元素 `:focus-visible` 有 2px 外环（accent-soft）+ 1px accent 描边，不做 `outline:none`。

### 7.4 焦点管理

- 切换选中行：焦点留在被点的行（鼠标）或列表容器（键盘）。
- 行尾开关获得焦点时该行保持选中；切换后焦点留在开关上（若行被移除则移到新选中行）。
- 「工具与参数」面板展开后焦点不抢入；用户 Tab 进入工具列表，`↑/↓` 在工具间移动（切换时右侧参数表随之更新）。
- 删除完成后焦点移到新选中行；列表为空时焦点到主 CTA。
- 详情内的折叠区（工具与参数/使用记录）展开后**不**抢焦点；用户 Tab 进入。
- 安装/编辑/确认对话框：焦点落入首个输入框或「取消」；关闭后焦点回到触发按钮（Modal 现状需补焦点回填）。

### 7.5 滚动位置保持

| 对象 | 记忆键 | 时机 |
|---|---|---|
| 本项目组滚动 | `domain:group` | 切域、切选中、静默刷新后恢复 |
| 全局组滚动 | `domain:group` | 同上 |
| 详情滚动 | 行 key | 选中变化时重置到 0；操作后刷新保持 |
| 目录树滚动 | 技能 rowKey | 切文件时保持，切技能重置 |
| 阅读器滚动 | `rowKey + 文件路径` | 切文件后回到该文件上次位置；首次打开 SKILL.md 到顶部 |
| 搜索框 | 域级 | 切域保留各自搜索词？**否**：切域清空搜索（避免"在 MCP 域看到技能搜索词"的错位），但保留在域内切选中 |

- 实现建议：用 `useRef<Map<string, number>>` 存内存，`scrollTop` 在 `requestAnimationFrame` 后恢复；不持久化到 localStorage（会话内即可）。
- 静默刷新（轮询）**不得**改变滚动位置与选中。

- 首次加载：列表显示 4 行骨架（h 76，内部灰条：名称 60% 宽 h 14、描述 90% 单行 h 12、右侧开关占位 30×18；底色 `--skp-fill`，1.2s 呼吸，`prefers-reduced-motion: reduce` 时静止）。

| 类型 | 位置 | 样式 | 交互 |

### 7.8 操作后局部刷新

- 一律用 `reload({ silent: true })` 重拉当前域数据，不整页 loading、不重建列表 DOM（保持滚动）。
- 写操作成功：行内 600ms 高亮脉冲（`--skp-accent-soft` 背景淡出），不弹 toast 除非是跨组可见变化（导入/安装/删除 → toast）。
- 乐观更新只用于布尔开关（启用/默认开关），失败回滚并显示错误条。
- 删除后：选中下一行（同组），组空则选另一组首行，全空则空态。
- 安装/导入成功：自动滚动到目标组新行并选中 + 高亮。

### 7.9 确认对话框（删除等破坏性操作）

- 复用现有 `Modal` 外壳：宽 520，圆角 14，标题 18/600，正文 13.5，底部右侧按钮组。
- 触发：删除技能/删除 MCP/移出引用/覆盖导入。
- 结构：标题（动词 + 名称）→ 影响说明（1–2 行，说明作用域影响）→ 可选「不再提示」？**不做**（删除是低频破坏性操作，保留确认）→ 按钮 `取消`（default，默认焦点）/ `删除`（danger 实心）。
- 文案示例见 8.5。
- 键盘：`Esc` = 取消；`Enter` 不默认触发删除（避免误按），必须 Tab 到删除按钮再 Enter。
- **统一口径（已定稿，Lead 2026-10-23）**：现状技能/MCP 删除都用"两击确认"（`panel.tsx:434-456`），本规格统一改为**确认对话框**，两击确认废除。理由：两击确认对读屏用户不可感知、误触后无法撤销，且与「覆盖导入」的确认方式不一致。
- 对话框必须包含**作用域后果**：项目删除说明只影响本项目；全局删除说明影响所有项目；屏蔽占位删除说明是"恢复同名全局技能"。

### 7.10 提示（toast / 行内）

- 成功类短反馈用轻量 toast（右下角，200×auto，圆角 8，2.5s 自动消失，`--skp-surface` + 阴影）：安装成功、导出已开始、路径已复制。
- 失败类**不用** toast，用行内错误条（用户需要看到与哪一项相关）。
- toast 不阻塞交互、不抢焦点；`aria-live="polite"`。

### 7.11 可访问性清单

1. 列表：`role="listbox"` + 行 `role="option"` + `aria-selected`；组用 `role="group"` + `aria-label`（含计数）。
2. 域 Tab：`role="tablist"` / `role="tab"` / `aria-selected`；面板 `role="tabpanel"`。
3. 状态点：`<span class="skp-dot" aria-hidden="true">` + 行内 `sr-only` 文本（如「已启用」「部分禁用」「已禁用」）。
4. 目录树：`role="tree"` / `treeitem` / `aria-expanded` / `aria-level`；根行与文件夹用 `treeitem`，选中文件 `aria-selected`。
5. 阅读器：可聚焦滚动容器 `tabindex=0` + `aria-label="<文件名> 内容"`；`预览/源码` 为 `role="tablist"` 或分段按钮组（`aria-pressed`）。
6. 开关：原生 `input[type=checkbox]` + `role="switch"`（现状 `.skp-switch` 已是原生 input，保持）。
7. 颜色对比：正文/次级文字 ≥ 4.5:1，标签文字 ≥ 4.5:1（标签用 `--skp-text-2` 不用更浅色）；状态点不能是唯一信息载体（必须有文本/标签）。
8. 焦点环：2px，始终可见；`prefers-reduced-motion: reduce` 时禁用呼吸/脉冲动画。
9. 对话框：`role="dialog"` + `aria-modal="true"` + `aria-labelledby`；打开时焦点进入，关闭回填。
10. 触控目标：行高 ≥ 44（列表行 72/76 达标）；图标按钮 ≥ 28×28 可点区扩到 32×32。
