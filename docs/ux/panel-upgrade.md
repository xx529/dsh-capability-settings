## 1. 背景与目标

### 1.1 三条用户需求

1. **快捷消息整个功能模块去除**：域 Tab 只剩「技能 / MCP」。
2. **技能明细看得到完整内容**：详情里展示 `SKILL.md` 正文，以及该技能目录下的其他文件，可在面板内逐个查看。
3. **选中域 Tab 后同时清楚看到「全局有什么、项目有什么」**，减少点击。

### 1.3 目标：点击预算（可验收，v7）

| 任务 | 上一版（v6 同屏双组 / 第三轮下钻） | **v7（当前）** |
|---|---|---|
| 看全局有什么 | 0 次（首屏可见） | **1 次**（左导航「全局」），中间列只列全局条目 |
| 看某个项目的技能 | 0–1 次（同屏或头上钉选） | **1 次**（项目 scope 下直接在左导航点工作区），之后 1 次/项 |
| 切换项目 | 头部下拉 1 次 + 选 1 次 | **1 次**（左导航工作区列表直接点另一个工作区）；头部下拉仍可选 |
| 安装/添加（当前 scope） | 工具条 CTA 1 次 | **1 次**（左导航该行右侧「+」） |
| 启用/禁用一个技能、项目内禁用全局技能 | 1 次（行尾开关） | **1 次**（行尾开关，不变） |
| 看某技能的 SKILL.md | 1 次（选中行） | **1 次**（不变） |
| 看技能目录里某个文件 | 1 次（目录树） | **1 次**（不变） |
| 安装全局技能到本项目 | 2 次（选中 → 详情按钮） | **2 次**（全局条目选中 → 详情「安装到本项目」；需先选过工作区，否则置灰） |
| 查看 MCP 某工具的参数 | 2 次 | **2 次**（不变） |
| 切到 MCP 域 | 1 次 | 1 次（不变） |

> 取舍：第三轮用「先确认工作区」换「作用域归属清晰、列表容量更大」；**v7 把工作区列表收进左导航后，进入/切换项目都只需 1 次点击**，中间列完整留给条目与详情。左导航「项目」计数在未选工作区时显示 `—`；未选时中间列只给一句「请选择左侧工作区」。

### 1.4 非目标

- 不重做外壳（侧栏、会话头部、输入框）与「会话内能力 Tab」；本规格只覆盖侧栏「能力面板」主区域页。
- 不新增创建/编辑技能的富文本编辑器（沿用现有安装/编辑对话框）。
- 不改 MCP 挂载、`restrict`、探测的宿主语义；只改呈现。
- 不做市场/说明页风格的内容，页面保持工具属性。

## 2. 设计原则与约束

1. **作用域显式化**：作用域用左导航「全局 / 项目」表达，一次只呈现一个作用域；项目必须显式选工作区，不把"当前会话工作区"当隐式上下文。
2. **状态就地可见**：来源、格式、启用、覆盖关系、挂载状态都必须在行上可读，详情只做展开。
3. **信息前置**：正文（SKILL.md）是技能的主体，必须成为详情页主体，不再是附属字段。
4. **零新依赖**：文件类型用 11px 文本后缀标签（`MD` / `PNG` / `JSON`…），不用新图标库；Markdown 用自研轻量渲染或原文等宽展示；骨架用纯 CSS。
5. **键盘可达、可读屏**：所有行内控件（开关）用 Tab 可达；列表用 `listbox/option` 语义；状态点必须带 `sr-only` 文本。
6. **只读即置灰，不是隐藏**：只读来源（`.claude` 兼容根、外部注入 MCP）的不可用动作置灰 + tooltip 说明原因，让用户理解「为什么不能改」。
7. **每行只给一个开关**（v2）：行内唯一控件是行尾开关；其余动作全在详情，不做 hover-only 功能、不做二级菜单。

## 3. 信息架构（v7）

### 3.1 层级

```
侧栏「能力面板」（主区域整页）
└─ 面板
   ├─ 头部（两行）
   │  ├─ 第一行：能力面板 · 当前工作区路径 · 项目作用域下拉
   │  └─ 第二行：[ 技能 12 ] [ MCP 9 ]                    [ 🔍 搜索… ]
   └─ 内容区（三列）
      ├─ 左：ScopeNav 208
      │     ├ 全局  12              ← 行尾「+」
      │     ├ 项目  —（或 N）        ← 行尾「+」；未选工作区时 + 置灰
      │     └ （project scope 时）工作区列表：Desktop / HtDot / … / LiveShopping（选中）
      ├─ 中：列表面板 280
      │     ├ 全局 scope → 全局条目（MCP：全局条目 + 外部注入第二组）
      │     └ 项目 scope → 已选工作区的条目；未选时只有标题 +「请选择左侧工作区」
      └─ 右：详情 694
```

### 3.2 头部：域 Tab 左 + 搜索右（v7）

- **第一行不变**：标题 `能力面板`（17/600）+ 当前工作区路径（12.5 弱色，单行省略）+ 右侧「项目作用域」下拉（200×34，`跟随当前会话` / 已知工作区）。
- **第二行**（新）：左侧域 Tab（`技能` / `MCP`，带计数），**右侧搜索框**——原视图内的「搜索 + 安装」工具条删除，安装/添加入口移到左导航每行的「+」。
  - Tab：容器宽 360（min 280），两等分，Tab 高 34；计数 11/600（选中变 accent）；切域**清空搜索词**。
  - 搜索：flex 0 1 420（min 160），高 34，右对齐；placeholder 按域切换（`搜索技能…` / `搜索 MCP 服务器…`）；`Esc` 清空、`/` 聚焦。
- **搜索只作用于当前列表面板**（不跨 scope、不跨工作区）：
  - 技能 · 全局 → `name` / `description`；
  - 技能 · 项目未选工作区 → 工作区 `basename` / 完整路径；
  - 技能 · 项目已选 → `name` / `description`；
  - MCP 同构（全局 → `key`/`summary`；工作区页 → 工作区名/路径；项目页 → `key`/`summary`）。
- 计数口径不变：技能 = 项目 + 全局条目数（含只读、含屏蔽占位，不去重）；MCP = 项目 + 全局配置条目数（不含外部注入）；加载中 `—`，搜索不改变计数。

### 3.3 左导航（ScopeNav）+ 工作区列表（v7 核心）

**左导航结构**：顶部两行 scope（每行 36 高）+ 在「项目」行下方**内嵌工作区列表**（仅 project scope 显示；global scope 隐藏）。

| 区域 | 规格 |
|---|---|
| 容器 | 宽 208、padding 8、右 1px 分隔；`overflow:hidden`（滚动只发生在工作区列表内） |
| 全局行 | `全局` 13.5/600 + 计数 11/600（右对齐）+ 行尾「+」24×24 |
| 项目行 | `项目` + 计数（未选工作区 `—`，已选 = 该工作区条目数）+ 行尾「+」（未选工作区时置灰，tooltip「先选择工作区」）；当前 scope 高亮 |
| 工作区列表 | 顶部 1px 分隔 + 4px 间距；`flex:1`、`overflow-y:auto`（nav 内滚动）、行间距 1；行高 **34**、圆角 6、左内边距 12 |
| 工作区行 | 名称 = 文件夹 basename（12.5，单行省略，`title` = 完整路径）；**选中态**：底 `#2A303B` + 左侧 2px 蓝条（上下内缩 6px）+ 文字提亮；hover 提亮 |
| 列表空态 | `.skp-scope-empty`：11.5 弱色，内容「没有工作区」；未选工作区且搜索中则为「无匹配」 |

**行为**：

- **仅 project scope 显示**工作区列表；切到全局 scope 时整段隐藏，nav 恢复为两行。
- 点工作区 = 钉选该项目（与头部「项目作用域」下拉**同一状态** `pinned`，两边同步）；切工作区会清空选中并把中间列切到该工作区条目。
- **中间列不再承载工作区列表**：只保留「标题 + 计数 + 条目」；项目未选工作区时显示居中空态 **「请选择左侧工作区」**（详情同时提示「请选择左侧工作区，再查看或安装本项目技能。」）。
- **「‹ 工作区」返回行已删除**：切回“未选”状态用左导航/头部下拉操作，不再有返回按钮。
- **搜索与工作区列表**：项目未选工作区时，头部搜索**同时过滤左侧工作区名/路径**（列表显示匹配项，无匹配显示「无匹配」）；**已选工作区后**工作区列表恢复完整（便于切换），搜索只过滤中间列条目。
- 全局 scope：中间列标题「全局技能」/「全局 MCP」+ 计数，只列全局条目；MCP 在下方追加第二组「外部注入」（组头 + 计数 +「运行时注入 · 只读」，仅非空时出现）。
- 切 scope / 切工作区都清空选中；关系标签互跳会切 scope、必要时自动钉选当前工作区，再选中目标行（§3.5）。
- **旧「同屏双组」与旧「中间列工作区选择页 / ‹ 工作区」均已删除。**

**为什么把工作区放左导航（与备选对比）**

| 方案 | 优点 | 缺点 | 结论 |
|---|---|---|---|
| **A. 工作区列表入左导航（v7，采用）** | 中间列完整留给条目；进/切项目都 1 次点击；层级一目了然 | 工作区多时需在 nav 内滚动（行高 34，密度高） | ✅ |
| B. 工作区列表放中间列（v6，已弃用） | 名称 + 完整路径更宽；中间列可当“选择页” | 未选时中间列被列表占满、条目区空置；多一步返回 | ❌ |
| C. 顶部下拉选项目（v2 及以前） | 不占版面 | 与 scope 导航语义重叠；看不到有哪些项目 | ❌ |

### 3.5 同名 / 同键覆盖关系（跨 scope 互跳）

宿主按 rank 让项目条目遮蔽全局同名条目。v7 不再同屏，关系通过**标签 + 可点击互跳**表达：

| 情况 | 项目 scope 那一行 | 全局 scope 那一行 |
|---|---|---|
| 仅全局存在 | 不出现 | 正常行，行尾开关 = 在本项目禁用/恢复 |
| 仅项目存在 | 正常行（可启停） | 不出现 |
| 项目副本 + 全局同名 | 标签 `覆盖全局` | 标签 `项目副本生效中`（整行弱化 60%） |
| 本项目已禁用全局（shadow stub） | 标签 `屏蔽占位`，状态点空心 | 标签 `本项目已禁用` |
| MCP：项目引用/导入 + 全局同名 | 标签 `引用` / `导入` | 标签 `被遮蔽` |
| MCP：项目同名覆盖 | 正常行 | 标签 `被遮蔽`（灰化） |

**互跳规则**（标签可点击，实现见 `panel.tsx` 的 `jumpToRelated`）：

- 项目行 `覆盖全局` → 切到**全局** scope 并选中同名行；
- 全局行 `项目副本生效中` / `本项目已禁用` → 切到**项目** scope（左导航工作区列表随之出现）；若尚未选工作区，先自动钉选**当前会话工作区**（若在已知工作区列表里；否则不动），列表刷新后选中同名行；
- 互跳不改搜索词；目标行被当前搜索过滤掉时不跳（避免"跳到看不见的行"）。

## 4. 布局与尺寸（1440×900，v7）

### 4.1 画框分区（实现 CSS 实测）

画框 1440×900 = 外壳侧栏 256 + 主区 1184×900。

> **与 v7 原型的像素差**：`docs/figma/prototype/v7/spec-v7.md` 把中列画成 300、详情 676（内容 628）；
> 当前实现为 **中列 280 / 详情 694（内容 646）**，目的是让技能目录树保持常驻（内容宽 <632 会折叠成下拉）。
> 两者**行为与层级一致**，只是像素分配不同；后续统一到哪一版由 Lead 拍板（见 §12 开放问题）。

```
主区 1184 × 900
├─ 页面头部                     y 0    h ≈ 121（含 1px 下边框）
│  ├─ 第一行（标题行）           y 0    h 34   padding 18 20 0
│  ├─ 14 间距
│  └─ 第二行（Tab + 搜索）       y 62   h 40   padding 0 20；下内边距 14
├─ 内容区                       y 121  h 779  display:flex
│  ├─ 左 ScopeNav   w 208（padding 8；右 1px 分隔）
│  ├─ 中 列表面板   w 280（padding 8；右 1px 分隔）
│  └─ 右 详情       w 694（padding 20 24 → 内容宽 646）

### 5.4 行尾统一开关（v2 定稿：无文字按钮、无 `⋯` 菜单）

**已确认原型 v2 的核心理念：行 = 扫读 + 一个开关；动作 = 全部在详情。** 每行右端统一为「短 label + 30×18 开关」，不再有行内文字动作按钮或二级菜单。

| 行类型 | label | 开（knob 右） | 关（knob 左） | 点击行为 | 置灰 / tooltip |
|---|---|---|---|---|---|
| 项目 · 普通可写 | `启用` | 模型与用户均可用（整体启用） | 已禁用（用户与模型都不可调用） | `setEnabled(next)`；`partial`（仅一个方向可用）显示为开，tooltip 标注「部分禁用」 | 只读来源 → 置灰 |
| 项目 · 屏蔽占位 | `启用` | —（恢复态） | 已禁用（本项目屏蔽同名全局） | 关 → 开 = `enableInProject`（删除占位） | 无工作区 → 置灰 |
| 全局 · 未被遮蔽 | `启用` | 本项目可用 | 已在本项目禁用 | 关 = `disableInProject`（生成占位）；开 = `enableInProject` | **面板未选工作区 → 置灰**（项目级动作需要工作区） |
| 全局 · 本项目已禁用 | `启用` | 本项目可用 | 已禁用（占位存在） | 开 = `enableInProject` | **面板未选工作区 → 置灰** |
| 全局 · 项目副本生效中（`projectShadow === "skill"`） | `启用` | 置灰、knob 在右 | — | 不可点 | tooltip「本项目生效的是项目副本，请在项目副本上操作」 |
| 只读来源（`.claude`） | `启用` | 置灰、按读到的状态摆位 | 置灰 | 不可点 | tooltip「只读来源，无法修改或删除」 |

- **尺寸/颜色**：30×18、knob 14、圆角 999；开 = `--skp-accent`；关 = 白 13%；置灰 = 轨道白 8% + **knob 在右**；label 10.5 / `--skp-text-3` / 宽 32 / 右对齐，与开关间距 6；label 在置灰时**不降透明度**（与普通行一致）。
- **置灰 ≠ 关闭**：置灰态与关态都可能是浅色轨道，唯一区别是 knob 位置（置灰恒在右）与可交互性；因此置灰必须同时具备 tooltip 与 `aria-disabled`，不能让用户只靠颜色判断。项目副本生效中的行**状态点仍为绿**（该全局技能可用），开关置灰表达"本项目不能直接操作"。
- **状态映射**：`checked = invocationState !== "none"`；`partial`（仅用户或仅模型）→ 视觉为开，但 tooltip 写「仅用户可用 / 仅模型可用」；细粒度两方向开关保留在详情（P2，原型未画）。
- **执行**：点击**不改变选中**（`stopPropagation`）；乐观切换 → 静默重拉确认；失败回滚 + 详情错误条；执行中开关 `disabled`（不换 loading 图标）。
- **键盘**：开关是原生 `input[type=checkbox][role=switch]`，`Space` 切换；行 `Enter` 只打开详情；`Tab` 从行进入开关。
- **触控**：开关外层 32×32 可点区；行高 76 本身远超 44。
- **无障碍**：`aria-label="启用 <技能名>"`；置灰时 `aria-disabled` + tooltip 文本进 `aria-describedby`。
- **MCP 行尾**同为「label + 开关」，label 固定 `默认`，语义不变（新建对话默认启用），见 §6.3。
- **工作区依赖**：全局 scope 里这些是"对本项目"的动作，因此**先在项目 scope 选过工作区**（`pinned !== undefined`）才可用；未选时开关置灰 + tooltip「需要可写的工作区才能修改技能」。

### 5.9 Markdown 预览渲染（零新依赖，v2 版式）

按投入从低到高三级，**任一级都不得引入第三方库**：

| 级别 | 做法 | 呈现 | 何时用 |
|---|---|---|---|
| L0 原文等宽 | `<pre>` + 等宽字体，保留换行 | 与文件内容完全一致 | 兜底；`源码` 视图用它 |
| **L1 轻量结构渲染（默认，与上一版原型帧 01/02 一致）** | 自研 ~100 行：识别 `#`（1–3 级）、`- / * / 1.` 列表、`>` 引用、` ``` ` 围栏代码块、`---`、段落；行内只处理 `` `code` `` 与 `**粗体**` | h1 15/600（不加 `#`）、h2 13.5/600、h3 13/600；段落 12.5/1.75；列表前缀 `• `（无序）/`1. `（有序），左缩进 12；引用 = 2px 左侧竖条（`--skp-border-strong`）+ 缩进 12、文字 `--skp-text-2`；代码块 = 底 `#151920`（`--skp-fill` 深档）、圆角 8、内 padding 12 14、Menlo 11.5/1.7、可横滚；行内 code = 同底色小圆角 pill | 默认 |
| L2 增强 | 表格渲染为等宽对齐块；链接渲染为可点文本（accent，新窗口，`rel=noopener`）；图片**不加载外链**，渲染「图片：<alt/文件名>（不预览）」占位 | 略强 | P2 |

**明确不做**：不 `dangerouslySetInnerHTML`、不解析内联 HTML、不远程拉图、不加载 iframe、不做语法高亮、不做目录侧栏。零依赖、无 XSS 面。

**降级判定**：渲染器抛错时回落到 L0，并在正文顶部显示 24 高提示「Markdown 渲染失败，已显示原文」。

### 6.3 行尾开关（v2：行内只有「默认」开关，无文字按钮、无菜单）

**与技能域同一交互形态**：行尾 = label + 30×18 开关；「默认」开关是**行内唯一控件**，其余动作（编辑、查看工具与参数、使用记录、删除/移出、导入）全部在详情动作区。

| 行类型 | 行尾开关 | 语义 / 行为 | 置灰 |
|---|---|---|---|
| 项目（非引用/非导入） | `默认` + 开关 | 开 = 新建对话默认启用；关 = 默认关闭（写 `capability-overrides.json`） | 配置内硬关闭时置灰 |
| 项目引用 / 导入副本 | `默认` + 开关 | 同上（项目级默认关闭标记） | 同上 |
| 全局 | `默认` + 开关 | 同上（项目级 overrides，对新建对话生效） | 同上 |
| 外部注入 | `默认` + 开关 | 同上；通过 `restrict` 按项目屏蔽 | `restrictable === false` 时置灰 |

## 7. 交互细节

### 7.1 默认选中（v7）

1. 进入面板 → 域默认「技能」，scope 默认「项目」。
2. 项目 scope 未选工作区：左导航「项目」行下方列出全部工作区；中间列显示「请选择左侧工作区」，**不选中任何条目**；详情显示「请选择左侧工作区，再查看或安装本项目技能。」。
3. 点左导航任一工作区（或在头部下拉里选工作区）：该工作区行变为选中态（高亮 + 左蓝条），中间列切到该项目条目；列表为空则不选中（空态），非空则选中第一行。
4. 切到全局 scope：左导航工作区列表隐藏；全局列表非空则选中第一行，否则不选中（空态）。
5. 切 scope / 切工作区 / 切域：**清空选中**（视图条件渲染会重建 scope 与选中，不做跨域记忆）。
6. 删除当前选中：选同列表下一行，没有则上一行；列表空则详情空态。
7. 搜索过滤掉选中行：保留选中（详情仍显示），清空搜索后恢复高亮；若此时按 ↑↓，以当前过滤结果重新定位。

### 7.2 搜索（头部第二行，v7）

- **位置**：页面头部第二行右侧（与域 Tab 同一行），**不在列表面板内**。
- **作用范围**：只过滤当前的可见列表，**不跨 scope**：
  - 技能 · 全局 → 全局条目 `name` / `description`；
  - 技能 · 项目**未选工作区** → **左导航工作区列表**（`basename` / 完整路径），中间列保持「请选择左侧工作区」空态；
  - 技能 · 项目**已选** → 该项目条目 `name` / `description`；左导航工作区列表**保持完整**（便于直接切换，不随搜索收缩）；
  - MCP 同构（全局 → `key`/`summary`；未选工作区 → 左导航工作区名/路径；已选 → `key`/`summary`）。
- **即时本地过滤**（无网络请求），去首尾空格、不区分大小写。
- **计数**：技能 · 全局标题显示 `匹配/总数`；MCP 标题显示当前过滤后条数（无分母）；左导航工作区列表不显示计数，仅保留匹配行（无匹配显示「无匹配」）。
- **清空**：`Esc` 清空；`type=search` 自带清除按钮保留。
- **切域**：清空搜索词；切 scope / 切工作区**保留搜索词**（同一份输入，作用到新列表）。
- **不改变**：域 Tab 计数（总量）；无匹配时不隐藏列表结构，显示空态文本。

| 按键 | 作用域 | 行为 |
|---|---|---|
| `↑` / `↓` | 中间列 | 上/下移动选中（不分页、不循环） |

| `Space` | 行尾开关 | 切换开关（能力域=启用/在本项目禁用；MCP=默认），不打开详情 |
| `/` | 页面 | 聚焦搜索框（输入框/文本域内不生效） |
| `Esc` | 搜索框 | 有内容 → 清空；无内容 → 焦点回列表 |
| `Esc` | 详情 | 焦点回列表当前行 |

### 7.4 焦点管理

- 切换选中行：焦点留在被点的行（鼠标）或列表容器（键盘）。
- 行尾开关获得焦点时该行保持选中；切换后焦点留在开关上（若行被移除则移到新选中行）。
- 「工具与参数」面板展开后焦点不抢入；用户 Tab 进入工具列表，`↑/↓` 在工具间移动（切换时右侧参数表随之更新）。
- 删除完成后焦点移到新选中行；列表为空时焦点到主 CTA。
- 详情内的折叠区（工具与参数/使用记录）展开后**不**抢焦点；用户 Tab 进入。
- 安装/编辑/确认对话框：焦点落入首个输入框或「取消」；关闭后焦点回到触发按钮（Modal 现状需补焦点回填）。

### 7.8 操作后局部刷新

- 一律用 `reload({ silent: true })` 重拉当前域数据，不整页 loading、不重建列表 DOM（保持滚动）。
- 写操作成功：行内 600ms 高亮脉冲（`--skp-accent-soft` 背景淡出），不弹 toast 除非是跨组可见变化（导入/安装/删除 → toast）。
- 乐观更新只用于布尔开关（启用/默认开关），失败回滚并显示错误条。
- 删除后：选中下一行（同组），组空则选另一组首行，全空则空态。
- 安装/导入成功：自动滚动到目标组新行并选中 + 高亮。

### 7.9 确认对话框（删除等破坏性操作）

- 复用现有 `Modal` 外壳：宽 520，圆角 14，标题 18/600，正文 13.5，底部右侧按钮组。
- 触发：删除技能/删除 MCP/移出引用/覆盖导入。
- 结构：标题（动词 + 名称）→ 影响说明（1–2 行，说明作用域影响）→ 可选「不再提示」？**不做**（删除是低频破坏性操作，保留确认）→ 按钮 `取消`（default，默认焦点）/ `删除`（danger 实心）。
- 文案示例见 8.5。
- 键盘：`Esc` = 取消；`Enter` 不默认触发删除（避免误按），必须 Tab 到删除按钮再 Enter。
- **统一口径（已定稿，Lead 2026-10-23）**：现状技能/MCP 删除都用"两击确认"（`panel.tsx:434-456`），本规格统一改为**确认对话框**，两击确认废除。理由：两击确认对读屏用户不可感知、误触后无法撤销，且与「覆盖导入」的确认方式不一致。
- 对话框必须包含**作用域后果**：项目删除说明只影响本项目；全局删除说明影响所有项目；屏蔽占位删除说明是"恢复同名全局技能"。

### 7.10 提示（toast / 行内）

- 成功类短反馈用轻量 toast（右下角，200×auto，圆角 8，2.5s 自动消失，`--skp-surface` + 阴影）：安装成功、导出已开始、路径已复制。
- 失败类**不用** toast，用行内错误条（用户需要看到与哪一项相关）。
- toast 不阻塞交互、不抢焦点；`aria-live="polite"`。

### 7.11 可访问性清单

1. 列表：`role="listbox"` + 行 `role="option"` + `aria-selected`；组用 `role="group"` + `aria-label`（含计数）。
2. 域 Tab：`role="tablist"` / `role="tab"` / `aria-selected`；面板 `role="tabpanel"`。
3. 状态点：`<span class="skp-dot" aria-hidden="true">` + 行内 `sr-only` 文本（如「已启用」「部分禁用」「已禁用」）。
4. 目录树：`role="tree"` / `treeitem` / `aria-expanded` / `aria-level`；根行与文件夹用 `treeitem`，选中文件 `aria-selected`。
5. 阅读器：可聚焦滚动容器 `tabindex=0` + `aria-label="<文件名> 内容"`；`预览/源码` 为 `role="tablist"` 或分段按钮组（`aria-pressed`）。
6. 开关：原生 `input[type=checkbox]` + `role="switch"`（现状 `.skp-switch` 已是原生 input，保持）。
7. 颜色对比：正文/次级文字 ≥ 4.5:1，标签文字 ≥ 4.5:1（标签用 `--skp-text-2` 不用更浅色）；状态点不能是唯一信息载体（必须有文本/标签）。
8. 焦点环：2px，始终可见；`prefers-reduced-motion: reduce` 时禁用呼吸/脉冲动画。
9. 对话框：`role="dialog"` + `aria-modal="true"` + `aria-labelledby`；打开时焦点进入，关闭回填。
10. 触控目标：行高 ≥ 44（列表行 72/76 达标）；图标按钮 ≥ 28×28 可点区扩到 32×32。
