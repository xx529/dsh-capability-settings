## 6. 已知风险

1. **composer 文案定位**：02 依赖 `composer-card` 内含「描述你想要构建」的 TEXT 节点；若基座文案改动导致找不到，脚本会跳过替换（其余照常绘制），需人工确认草稿文案。
2. **面板高度自适应**：04 实际高 394（不是 430）、03 高 380；原因见 §3。若要求严格 430 需上移面板或接受底部裁切。
3. **字形**：PingFang SC 不含 `✦` `✓`，依赖 Figma 缺字形回退（v9 导出已验证可用）；勾选框沿用 PingFang 自带的 `√`。
4. **克隆源**：`4:7` / `42:3376` 与节点名 `capability-panel`、`composer-card`、`header/search`、`header/tabs` 变更会导致 throw 或跳过。
5. **05 覆盖式重绘**：body 用不透明覆盖层，导出 scene 会包含被遮住的旧 body；卡片高度 720 使底栏 658 / 分隔线 648 下移，勿单独改高度而不移底栏。
6. **幂等边界**：01 会复位面板 920×320 并恢复底座子节点；单独重跑 01 后需重跑 02/03/04。标准顺序 00 → 01 → 02 → 03 → 04 → 05。
