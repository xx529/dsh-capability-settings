## 5. 每帧视觉验收点（各 3 条）

- **01**：① panel 内 tabs 行右侧出现蓝描边「✦ 自动选择」按钮，与 search/管理全部不重叠；② 按钮底为 12% 蓝、文字亮蓝 12px；③ 帧底一行注释在面板下方、未压面板。
- **02**：① 面板下沿与帧底之间留出注释行（面板未越界裁切）；② 6 行分数依次 0.93/0.88/0.81/0.76/0.64/0.42，前 5 勾选、第 6 行灰化未勾选；③ 阈值行显示滑杆 0.50 与「已选 5 / 37」，底栏「应用所选（5）」为蓝底主按钮。
- **03**：① 状态行 spinner +「正在评分…」+ 右侧「1 次请求 · 37 个能力」；② 5 条骨架行等距、无文字；③「取消评分」可用、「应用所选」禁用（灰底灰字），帧底注释在面板下。
- **04**：① 头部只有「技能 / MCP / Jev 模型」三项且第三项 active，右侧无搜索框；② 配置卡在主内容区居中（帧内 x=438、宽 820，左右各 182），卡内字段自 Base URL → 模型 → 密钥模式 → API Key 顺序排列、无重叠；③ 绿色成功 pill 文案完整为「✓ 连接成功 · jev-1.13.0 · 32ms」，底栏「保存配置」为主按钮。

## 6. 已知风险

1. **面板高度**：见 §3 自适应说明；若 Lead 要求严格 430，需要同时上移面板或接受底部 10px 裁切。
2. **克隆源**：`4:7` / `42:3376` 不存在或 `capability-panel`、`header/search`、`header/tabs` 改名时脚本会 throw（不静默产出错稿）。
3. **字形**：PingFang SC 不含 `✦` `✓`，依赖 Figma 的缺字形回退（v8 预览中同类的 `▸` 已正常回退）；勾选框改用 PingFang 自带的 `√`。若画布上「✦ 自动选择」/ pill 的 `✓` 显示为方框，替换为 `◆`/`√` 或改用矢量图形。
4. **scene 导出**：每帧多一层 `base-*` 克隆容器（page → frame → base），导出/导入仍可编辑，但层级比 v8 深一层。
5. **幂等边界**：01 会把面板复位为 920×320 并恢复底座子节点可见；若在 02/03 之后单独重跑 01，02/03 的结果内容需重新执行 02/03。标准顺序 00 → 01 → 02 → 03 → 04。
6. **04 覆盖式重绘**：body 用不透明覆盖层而非删除底座节点，导出 scene 会包含被遮住的旧 body（可编辑性不受影响，但节点数偏多）。
